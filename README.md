# GreekInSanskrit

_Created: 15-04-2015 · Last updated: 11-07-2026_

Supplying the **missing Greek-script text** for the Cologne digitizations of
Sanskrit dictionaries, and analysing the Greek material found in them.

Many printed Sanskrit–European dictionaries quote Greek words in Greek script
(etymologies, cognates, comparative notes). When those dictionaries were
digitized for the [Cologne Digital Sanskrit Dictionaries](https://www.sanskrit-lexicon.uni-koeln.de/)
project, the Greek passages were frequently dropped, garbled, or transliterated
lossily. This repository is the working space where those Greek passages are
recovered from the scans, checked, and fed back to the digitized texts.

## What is here

Analytical PDFs on the Greek material and on Sanskrit phonotactics:

- [CVCVCVCV.pdf](https://github.com/sanskrit-lexicon/GreekInSanskrit/blob/main/CVCVCVCV.pdf) — syllable-structure analysis
- [accent-percent.pdf](https://github.com/sanskrit-lexicon/GreekInSanskrit/blob/main/accent-percent.pdf) — accent-distribution statistics (IAST / SLP1)
- [endings.pdf](https://github.com/sanskrit-lexicon/GreekInSanskrit/blob/main/endings.pdf) — word-ending analysis
- [praefixoids.pdf](https://github.com/sanskrit-lexicon/GreekInSanskrit/blob/main/praefixoids.pdf) — prefixoid analysis

The substance of the recovery work lives in the repository's
[GitHub issues](https://github.com/sanskrit-lexicon/GreekInSanskrit/issues),
each tracking the Greek text of one source — e.g. Monier-Williams (`MW72`, split
across parts), Grassmann (`GRA`), Böhtlingk (`BUR`), the Buddhist Hybrid
Sanskrit dictionary (`BHS`), Mayrhofer/Indo-Germanisches (`INM`), Macdonell
(`MD`), Cappeller, Benfey, Bopp (`BOP`), and others, plus cross-cutting issues
(which dictionaries contain Greek, a non-Sanskrit word list, Perseus links).
